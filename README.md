# Rule-Based AI Python Chatbot

## About

This is a simple Rule-Based AI Chatbot developed using Python. The chatbot interacts with users through predefined responses and keyword matching. It can answer basic Python questions, provide motivational messages, tell jokes, and display the current date and time.

## Features

- Simple and interactive conversation
- Personalized greetings based on the current time
- Answers basic Python programming questions
- Provides motivational messages and jokes
- Displays the current date and time
- Stores conversation history during the session
- Includes a help command
- Supports multiple exit commands
- Beginner-friendly Python project

## Technologies Used

- Python
- Datetime module
- Random module
- Time module
- Dictionaries and lists
- Functions
- Loops and conditions
- String manipulation

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run the following command:

   `python main.py`

## How to Use

1. Run the Python program.
2. Enter your name to start the conversation.
3. Ask basic questions such as "hello" or "what is Python".
4. Type "help" to see the available commands.
5. Type "history" to view the conversation history.
6. Type "bye" to exit the chatbot.

## Purpose

This project was created to practice Python programming concepts and understand the basic working of a rule-based chatbot using predefined responses, functions, dictionaries, and conditional statements.
